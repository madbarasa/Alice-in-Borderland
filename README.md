# ♠️ Alice in Borderland: The Web Trials
![Version](https://img.shields.io/badge/version-1.3.1-red) ![Status](https://img.shields.io/badge/status-Advanced_Beta-green) ![Aesthetics](https://img.shields.io/badge/UI-Glassmorphism-blue)

基于《弥留之国的爱丽丝》世界观构建的高端沉浸式 Web 游戏套件。

## 🎮 游戏模式
- **闯关模式 (Campaign)**：按照难度梯度线性解锁（4 -> 5 -> 7 -> 9 -> Q -> K -> JOKER）。
- **生存模式 (Survival)**：全关卡解锁，自由选择挑战顺序。

## 🃏 关卡列表 (v1.3.1)
1. **♦ 4 灯泡谜题** - 逻辑推理的起点
2. **♠ 5 牢笼逃脱** - 物理与精神的双重压迫
3. **♥ 7 捉迷藏** - 狼与羊的信任崩塌
4. **♥ 9 地球侵略** - 找出潜伏的渗透者
5. **♠ Q 无限回廊** - 黑暗中的死线突围
6. **♣ K 单张牌对决** - 极致的算力博弈
7. **JOKER 摆渡人** - 通往现实的最终大门

## 🛠️ 技术与美学规范
- **视觉风格**：v1.2.0 Glassmorphism 标准（毛玻璃、霓虹强调、动态扫描线）。
- **代码架构**：CONFIG 驱动型模块化逻辑，状态集中管理。
- **持久化**：使用 `localStorage` 维护签证（Visa）及解锁进度。
